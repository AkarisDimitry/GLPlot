GLPlot Documentation
====================

High-performance GPU-accelerated plotting library for Python, designed to handle **millions** of geometric primitives effortlessly. GLPlot provides a Matplotlib-compatible API while running natively over an OpenGL/GLFW backend with GPU instancing and density visualization.
